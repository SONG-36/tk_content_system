# 03. Cleaning Video Hook Database

## Purpose

本文件不是普通标题库，而是车载清洁类内容的 Hook 机制库。

每类 Hook 都必须说明：

- Hook 机制
- 为什么有效
- 适合什么场景
- 如何迁移到车载清洁产品

本文件服务于：

- `01_TikTok_Viral_Analysis_Framework`
- `05_TikTok_Shop_Script_Writing_Rules`

---

## 1. Hook Design Rules

### 1.1 Hook 的目标不是“说一句狠话”

Hook 的任务是让用户在 1-3 秒内理解：

- 这里有问题
- 这个问题和我有关
- 接下来会看到结果

### 1.2 车载清洁类最强 Hook 通常满足至少两个条件

- 问题可视化
- 结果预告
- 脏污冲击
- 实用价值
- 情绪共鸣

### 1.3 优先使用视觉 Hook，再让文字补充

高效顺序：

1. 画面先停人
2. 文案再解释
3. 动作再证明

## 2. Hook Categories

### 2.1 Hidden Dirt Reveal

Hook 机制：

- 先暴露用户平时忽略的脏污
- 让“隐藏问题”变成显性冲突

为什么有效：

- 惊讶感强
- 自我代入快
- 用户会想看还能掏出多少脏东西

适合什么场景：

- 杯架底部
- 座椅缝
- 中控按键边缘
- 门板缝隙

如何迁移到车载清洁产品：

- 优先给到狭窄位置近景
- 第一镜不要先拍产品外观，先拍脏污证据

Hook 结构：

- “你以为这里不脏”
- “其实最脏的是这里”
- “看它能清出多少”

用户心理：

- 惊讶
- 洁癖满足
- 焦虑

适合产品：

- 缝隙刷
- 吸尘器细嘴
- 清洁胶
- 细节清洁套装

案例模板：

- “你车里最脏的不是脚垫，是这个缝。”

### 2.2 Before After

Hook 机制：

- 直接用视觉反差建立停留理由

为什么有效：

- 用户一秒看懂结果
- 反差天然带来完播欲望

适合什么场景：

- 中控台除尘
- 门板去污
- 杯架清洁
- 局部护理恢复

如何迁移到车载清洁产品：

- 优先做半边对比
- 保证光线和机位一致

Hook 结构：

- “左边是没擦，右边是擦完”
- “差别比我想的还夸张”

用户心理：

- 秩序恢复
- 爽感
- 结果确认

适合产品：

- 内饰喷雾
- 擦拭布
- 护理剂

案例模板：

- “只擦半边，你就知道车里到底有多脏。”

### 2.3 Cleaning Challenge

Hook 机制：

- 用“难清位置”制造挑战感

为什么有效：

- 用户天然会怀疑能不能清掉
- 挑战结构能制造悬念

适合什么场景：

- 陈年杯架污渍
- 宠物毛发
- 深缝灰尘
- 干掉的污点

如何迁移到车载清洁产品：

- 先建立“这里平时很难搞”
- 再用产品做现场验证

Hook 结构：

- “这个位置我一直清不干净”
- “试试它能不能搞定”

用户心理：

- 好奇
- 怀疑
- 期待反转

适合产品：

- 去污产品
- 强演示型工具
- 毛发清理工具

案例模板：

- “杯架这个陈年污渍，今天试试看能不能一次弄掉。”

### 2.4 Product Test

Hook 机制：

- 把视频开场变成产品能力验证

为什么有效：

- 用户会把观看转成“评测模式”
- 比直接夸产品更可信

适合什么场景：

- 新工具首测
- 多材质对比
- 死角演示

如何迁移到车载清洁产品：

- 开场提出明确测试目标
- 不要用空泛赞美

Hook 结构：

- “看看它能不能吸出这个缝里的灰”
- “这玩意到底是不是智商税”

用户心理：

- 怀疑验证
- 实用判断
- 风险控制

适合产品：

- 吸尘器
- 细节刷
- 清洁胶
- 电动清洁工具

案例模板：

- “我就测一个地方，看看它到底值不值得买。”

### 2.5 Problem Exposure

Hook 机制：

- 先放大不舒服、尴尬或掉价的问题

为什么有效：

- 共鸣快
- PAS 的 Problem 段自然成立

适合什么场景：

- 朋友上车看见杯架脏污
- 中控台厚灰
- 车门扶手积灰

如何迁移到车载清洁产品：

- 问题必须具体、可见、真实
- 不要用抽象抱怨

Hook 结构：

- “别人一上车最先看到的就是这里”
- “车里再贵，这里脏了都显旧”

用户心理：

- 共鸣
- 体面焦虑
- 解决欲望

适合产品：

- 内饰清洁类全品

案例模板：

- “很多车看起来旧，不是因为旧，是因为这里太脏。”

### 2.6 Satisfying Transformation

Hook 机制：

- 直接承诺一个“看着很爽”的变化过程

为什么有效：

- 用户会为了感官满足继续看
- 这类内容兼顾停留和分享

适合什么场景：

- 泡沫覆盖后擦净
- 黑水流出
- 灰尘被吸入透明盒

如何迁移到车载清洁产品：

- 选择最有反馈的动作做开头
- 尽量让第一镜就出现“变化正在发生”

Hook 结构：

- “这个画面看着太解压了”
- “看它一点点变干净”

用户心理：

- 爽感
- 替代参与
- 完成欲

适合产品：

- 喷雾
- 吸尘器
- 泡沫型清洁剂

案例模板：

- “如果你喜欢看解压清洁，这个杯架一定要看到最后。”

### 2.7 Expert Tip

Hook 机制：

- 借“我来告诉你一个更对的方法”建立权威和实用价值

为什么有效：

- 降低广告感
- 更容易被接受为技巧内容

适合什么场景：

- 细节位清洁
- 正确工具选择
- 常见错误替代

如何迁移到车载清洁产品：

- 先给技巧，再带产品
- 产品作为解决方案而不是硬切广告

Hook 结构：

- “很多人擦车内饰，最容易漏掉这个位置”
- “纸巾擦不干净，不是你懒，是工具不对”

用户心理：

- 学习
- 信任
- 风险规避

适合产品：

- 教育型和功能解释型产品
- 细节清洁工具
- 组合套装

案例模板：

- “想让车里看起来更干净，先处理这个最容易忽略的位置。”

## 3. Hook Selection Rules by Product

### 3.1 缝隙类产品

优先 Hook：

- Hidden Dirt Reveal
- Product Test
- Cleaning Challenge

### 3.2 喷雾和擦拭类产品

优先 Hook：

- Before After
- Satisfying Transformation
- Problem Exposure

### 3.3 吸尘器和强动作工具

优先 Hook：

- Product Test
- Hidden Dirt Reveal
- Satisfying Transformation

### 3.4 套装型产品

优先 Hook：

- Expert Tip
- Problem Exposure
- Before After

---

## 4. Hook Failure Patterns

以下开场通常低效：

- 一上来先讲品牌
- 一上来先展示包装
- 一上来先讲参数
- 问题不具体
- 结果不预告
- 画面太远，看不见脏污
