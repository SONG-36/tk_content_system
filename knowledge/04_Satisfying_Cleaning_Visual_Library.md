# 04. Satisfying Cleaning Visual Library

## Purpose

本文件沉淀车载清洁内容里最容易形成停留、爽感和信任的视觉机制。

每个机制都回答：

- 用户看到什么
- 为什么愿意继续看
- 为什么这会建立产品信任
- 适合什么产品和拍法

---

## 1. Visual System Rules

### 1.1 好看的清洁镜头不等于能卖货

高价值视觉必须同时满足：

- 有停留吸引力
- 有过程反馈
- 有结果证明

### 1.2 车载清洁类最强视觉来自“变化可见”

变化可见包括：

- 颜色变化
- 边界变化
- 颗粒移动
- 液体流出
- 材质恢复

### 1.3 视觉素材应优先承担证明功能

优先级：

1. 证明问题真实存在
2. 证明产品在起作用
3. 证明结果可以复制

---

## 2. Visual Mechanism Library

### 2.1 泡沫覆盖

视觉描述：

- 清洁剂或泡沫先覆盖脏污表面，形成“接管脏污”的第一层画面冲击

用户心理：

- 预期解决开始
- 视觉饱满感
- 专业护理联想

停留原因：

- 用户预判下一步会擦净
- 过程带有悬念和反馈

信任建立方式：

- 明确显示产品已接触目标区域
- 强化“不是空口说有效，而是正在处理”

适合产品：

- 内饰泡沫清洁剂
- 多功能喷雾
- 皮革或塑料件清洁产品

拍摄方式：

- 近景拍泡沫覆盖过程
- 保持脏污区域完整入镜
- 紧接下一镜擦除结果，避免断档

### 2.2 黑水流出

视觉描述：

- 清洗后流出的黑水、脏液或污渍残留被肉眼看到

用户心理：

- 脏污证据被“实体化”
- 隐藏问题被揭露

停留原因：

- 画面冲击强
- 用户会想知道还能流出多少

信任建立方式：

- 结果不是抽象“变干净”，而是脏污被明确排出

适合产品：

- 清洗剂
- 织物清洁
- 深层去污产品

拍摄方式：

- 深色接液面增强对比
- 尽量让脏液流动路径完整可见

### 2.3 灰尘吸入透明盒

视觉描述：

- 吸尘器工作时，灰尘和碎屑进入透明尘盒或可见通道

用户心理：

- 成果即时反馈
- “我能看见它真的吸进去了”

停留原因：

- 动作连续
- 反馈即时
- 容易形成“再吸一点”的观看惯性

信任建立方式：

- 产品工作结果可视化
- 降低“只是摆拍”的怀疑

适合产品：

- 便携吸尘器
- 透明集尘结构产品

拍摄方式：

- 尽量利用透明件近景
- 让吸入路径清晰，不要机位过远

### 2.4 缝隙掏出污垢

视觉描述：

- 用刷、钩、胶或吸头从狭窄区域掏出积灰、碎屑或毛发

用户心理：

- Hidden Dirt Shock
- 控制感恢复

停留原因：

- 用户想看“能掏出来多少”
- 难清区域天然有挑战感

信任建立方式：

- 清楚证明产品能处理普通工具处理不了的地方

适合产品：

- 缝隙刷
- 清洁胶
- 细长吸头

拍摄方式：

- 先拍缝隙脏污特写
- 再拍工具进入
- 最后拍掏出结果

### 2.5 一半脏一半净

视觉描述：

- 同一块区域保留一半脏污、一半清洁结果

用户心理：

- 对比确认
- 结果一眼可见

停留原因：

- 反差在一帧内完成
- 用户无需等待太久就能理解结果

信任建立方式：

- 最直观的 before/after 证据
- 减少“是不是换了场景”的怀疑

适合产品：

- 几乎所有车载清洁产品

拍摄方式：

- 固定机位
- 保持光线一致
- 清洁路径尽量笔直，方便形成清楚边界

### 2.6 连续擦拭变化

视觉描述：

- 擦拭、刷洗或吸附动作连续进行，结果随着动作推进不断显现

用户心理：

- 替代参与
- ASMR 式节奏满足
- 完成欲

停留原因：

- 连续动作有观看惯性
- 每一步都有反馈

信任建立方式：

- 过程没有被跳过
- 用户能看到效果不是剪辑硬切出来的

适合产品：

- 擦拭布
- 清洁喷雾
- 毛刷
- 吸尘器

拍摄方式：

- 不要切得过碎
- 保留足够长的动作段证明真实效果

### 2.7 工具进入困难区域

视觉描述：

- 工具顺利进入平时够不到、擦不到、吸不到的位置

用户心理：

- “终于有办法了”
- 功能理解瞬间完成

停留原因：

- 难点先被提出
- 解决动作马上跟进

信任建立方式：

- 直接证明结构优势
- 从功能参数转成场景化价值

适合产品：

- 细长吸头
- 弯头刷
- 超薄清洁片

拍摄方式：

- 先让用户看到普通工具不行
- 再让目标产品进入
- 镜头尽量贴近入口位置

### 2.8 材质质感恢复

视觉描述：

- 清洁后塑料件、皮革件或饰板恢复更均匀、更顺眼的表面状态

用户心理：

- 新车感恢复
- 体面感提升

停留原因：

- 用户会比较前后“旧感”差异

信任建立方式：

- 产品价值不只在去脏，还在恢复观感

适合产品：

- 内饰护理剂
- 去灰和上光类产品

拍摄方式：

- 利用斜侧光呈现表面状态差异
- 避免过度曝光导致质感看不清

## 3. Visual Assembly Rules

### 3.1 最佳顺序

建议按这个顺序组镜头：

1. 问题证据
2. 工具进入
3. 动作反馈
4. 结果边界
5. 定格对比

### 3.2 单条视频至少保留一个强视觉证据

优先级通常为：

- 一半脏一半净
- 缝隙掏出污垢
- 灰尘吸入透明盒
- 黑水流出

### 3.3 视觉失败模式

- 脏污拍不清
- 产品接触点看不见
- 过程跳太快
- 结果没有定格
- 光线和机位导致反差失真
